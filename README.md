# 📚 Online Education Platform

A simple and beginner-friendly HTML project that showcases the homepage of an online education platform. The page includes a welcoming hero section, a call-to-action button, and a list of popular courses.

## ✨ Features

- Welcome hero section
- Clean and simple layout
- "Explore Courses" button linking to another page
- List of popular courses
- Basic CSS styling
- Beginner-friendly HTML structure

## 🛠️ Technologies Used

- HTML5
- CSS3 (Internal Styling)

## 📂 Project Structure

```
Online-Education-Platform/
│
├── index.html
├── blog.html
└── README.md
```

## 🎯 Learning Objectives

This project was created to practice:

- HTML page structure
- Headings and paragraphs
- Lists (`<ul>` and `<li>`)
- Hyperlinks (`<a>`)
- Buttons
- Internal CSS styling
- Basic webpage layout

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Click the **Explore Courses** button to navigate to the courses page (`blog.html`).
